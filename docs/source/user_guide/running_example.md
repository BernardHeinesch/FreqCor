# Running the Example

FREQCOR is shipped with two example datasets from the ICOS Lonzée station (BE-Lon), covering the **same time window** — two spring months of 2024 over a winter wheat crop — processed with two different flux software:

- `examples/metadata/FREQCOR_config_example_EddyPro.ini` — inputs generated by **EddyPro**
- `examples/metadata/FREQCOR_config_example_GEddySoft.ini` — inputs generated by **GEddySoft**

Both configurations are set up to run a **cospectral** workflow for **CO2**, making it easy to compare the two input formats on identical data.

1. Run the main entry point:

   - Open `src/FREQCOR_Start.py` and run it (the *MANUAL MODE* section points to the EddyPro example INI by default — switch to `FREQCOR_config_example_GEddySoft.ini` to run the GEddySoft example).

2. In case of path problems, check the *MANUAL MODE* section in FREQCOR_Start.py for .ini file path, and the file paths in the corresponding `examples/metadata/FREQCOR_config_example_*.ini` file.

Outputs are written under `examples/output/` (or under the `output_path` configured in the INI file). For a description of the generated results, see the **Outputs** section.
